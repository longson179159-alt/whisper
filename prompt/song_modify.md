# Song Lyrics and Whisper Timestamp Alignment

Process song lesson folders that contain Whisper output and a separate lyrics file.

## Input structure

Each lesson is one directory with this structure:

```text
<lesson folder>/
├── raw_timestamp.json
├── raw_text.txt
└── lyrics.txt
```

- `raw_timestamp.json` is a JSON array of Whisper segments. Each segment contains:

```json
{
  "start": 4.64,
  "end": 9.32,
  "text": "Whisper segment text",
  "ts_idx": 0
}
```

- `raw_text.txt` contains the original complete Whisper transcript. Keep this file unchanged.
- `lyrics.txt` contains the song lyrics in their intended order. It may contain headings, blank lines, credits, annotations, or lyric lines that are absent from the particular audio/video version.

## Task

Align the words and repeated sections in `lyrics.txt` with the sequence and timestamps in `raw_timestamp.json`.

- Use the Whisper timestamps and song order to determine where each lyric line belongs.
- Replace Whisper transcription errors with the matching lyric wording.
- Handle repeated verses and choruses according to their actual positions in the Whisper output. Do not collapse repeated sections.
- Do not force lyric lines into the result when they are not present in this audio/video version.
- Remove non-lyric metadata such as section headings, credits, website text, and annotations.
- Remove obvious Whisper hallucinations that do not belong to the song.
- Keep meaningful sung ad-libs and backing vocals when the Whisper output supports their position.
- Preserve chronological timestamps. Adjust segment boundaries only when needed for alignment.
- Avoid extremely short fragments; merge them into a nearby lyric segment when appropriate.
- Preserve the JSON field structure, including `start`, `end`, `text`, and `ts_idx`.
- Before editing, create `raw_timestamp.before_lyrics_alignment.json` as a backup of the original `raw_timestamp.json`. Do not overwrite an existing backup.

## Output structure

After processing, the lesson directory must contain:

```text
<lesson folder>/
├── raw_timestamp.json
├── raw_timestamp.before_lyrics_alignment.json
├── raw_text.txt
├── lyrics.txt
└── text.txt
```

- `raw_timestamp.json`: aligned timestamp segments whose `text` values follow the lyrics and the actual audio sequence.
- `raw_timestamp.before_lyrics_alignment.json`: unchanged backup of the original timestamp file.
- `text.txt`: the final transcript generated by joining the `text` value of every segment in `raw_timestamp.json`, one segment per line.
- `raw_text.txt`: unchanged.
- `lyrics.txt`: unchanged.

## Required validation

Before reporting completion, verify that:

1. All JSON is valid and every segment contains the required fields.
2. Every segment has `start <= end` and segments remain chronological.
3. `text.txt` exactly matches the segment text in `raw_timestamp.json`.
4. Lyric wording and repeated sections follow the song sequence represented by the Whisper output.
5. Non-lyric metadata and unsupported lyric lines are absent from the output.
6. `raw_text.txt` and `lyrics.txt` were not modified.
7. The backup exists and matches the pre-edit `raw_timestamp.json`.

Process the requested lesson first as a pilot. Report the files changed, the number of output segments, any lyric lines intentionally excluded, and the validation result. For a batch, use the same rules for every lesson and report any uncertain lesson separately.
